# Synthetic knowledge exercise / 合成知识练习

The equipment and instructions below are fictional. Do not apply them to real devices.

## Manual AX10 / v1 / page 3

AX10 is a fictional inventory label reader. Error E03 means the input image is below the supported brightness range. The teaching procedure is to retry with the provided brighter sample image, then record the observed status. It does not authorize changing production hardware.

## Manual AX10 / v2 / page 4

This teaching revision supersedes AX10 v1 for firmware 2.0 only. E03 means that the selected image profile does not match the configured sample profile. Select the matching synthetic profile, then retry. Firmware 1.x remains on the v1 definition.

## Manual BX20 / v1 / page 7

BX20 is a fictional stock-count simulator. E03 means the local synthetic batch ID already exists. Query the batch status before retrying. Do not create a new batch ID merely to bypass the duplicate warning.
