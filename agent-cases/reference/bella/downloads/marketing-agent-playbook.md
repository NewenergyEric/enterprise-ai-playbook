# AIelsen · 全案营销 Agent 协作工作表

用途：将产品发布过程中的需求、事实、策略、内容和反馈连接起来。
本模板根据实战方法重新整理，不包含客户资料、项目数据或专有创意。

## 1. 开始之前：建立工作基线

| 字段 | 填写内容 |
| --- | --- |
| 本次业务目标 | 需要影响谁的什么决策？ |
| 目标人群与任务 | 不是只有画像标签，要写出具体使用任务 |
| 当前发布阶段 | 准备 / 预热 / 上线 / 持续运营 |
| 已确认事实 | 产品能力、适用条件、商业口径 |
| 未确认事项 | 具体问题、所需证据、确认人 |
| 现有材料 | 文件、版本、适用范围、是否允许对外 |
| 人与 Agent 的分工 | 谁提供事实，谁研究，谁判断，谁执行 |
| 完成标准 | 哪些资产、哪些受众、哪些问题必须覆盖 |

检查：不要把未确认的产品参数、价格、性能或安全信息写成对外承诺。

## 5. TVC 与脚本审核

| 卖点 | 原稿已有表达 | 状态 | 理解障碍 | 建议修改 | 需要的画面或证据 | 优先级 | 决策记录 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| | | 清楚 / 模糊 / 隐含 / 缺失 | | | | | |

审核顺序：

1. 明确原稿已经做好的内容和创意归属。
2. 检查核心产品边界和用户价值是否被讲清。
3. 找出名词堆叠、参数缺少解释、画面隐含但观众无法理解的问题。
4. 将每条建议写成可执行的镜头、字幕、口播或结构调整。
5. 检查时长、制作条件与证据可用性，再安排优先级。

每轮修改同时保留：反馈原意、具体改变、未采纳原因、仍需确认的事项。
“更高级”“更震撼”需要被翻译成可以共同观察和修改的对象。
概念图用于沟通创意，不应冒充已完成的产品实拍或最终客户效果。

## 8. 版本、隐私与发布复核

- [ ] 已确认素材没有在视觉改版中丢失。
- [ ] 核心事实与最新产品口径一致。
- [ ] 标题、图像、口播与实际内容一致。
- [ ] 未确认内容没有写成确定承诺。
- [ ] 原创、原稿、Agent 增量与团队最终制作的归属清楚。
- [ ] 客户名、内部代号、价格、数据、文件路径与链接按授权处理。
- [ ] 图片已物理裁剪或实色遮罩，不能只用网页遮盖原图。
- [ ] 原始素材与私有核对资料不进入公开发布目录。
- [ ] 版本、确认人和需要回看的问题有记录。

衡量的重点：产出是否支持下一步行动、事实是否一致、问题是否被回应、交接是否完整。
不要用产出数量或未经验证的采纳比例替代业务判断，也不要把销售成绩归因于单一工具。
